## Question

From *Wild Wild West* and *Mortal Engines* (and adjacent steampunk machinery fiction), which **mechanical motifs** are fair game as original systems, and which are IP-specific landmines?

Focus on: traction/mobile settlements, landships, industrial predation vs trade, showman superscience vs grim logistics, visual/mechanical hooks we can abstract.

Resolve with: motif list tagged adopt / adapt carefully / avoid; implications for Traction Settlements and Invention flavor. Asset path OK under `.scratch/wayfind-spec/assets/`.

## Answer summary

**Fair game (ADOPT):** rare relocatable industry; trains/landships/crawlers; mining-harvester mobility; track-scar environmental cost; trade/mobile entrepôt roles; automata as threats/units; Invention as budgeted parts with dual voice — *showman spectacle* vs *grim logistics reliability*; predation as Faction raid/policy, not world law.

**Adapt carefully:** wheeled/tracked city plates and tiered class stacks (change silhouette/fiction); multi-leg walkers (not spider/chicken-leg clones); gadget command trains; scavenged superweapons; animal-form prime movers; static-vs-mobile ideology without ME’s Anti-Traction package.

**Avoid (IP landmines):** Municipal Darwinism + jaws/Gut urbivore loop as default; ME proper nouns/set pieces (Gut, Hunting Ground, MEDUSA-in-cathedral, etc.); WWW eight-legged tarantula tank / Loveless–Wanderer packaging; GG “Spark”/Heterodyne castle-AI branding.

**Traction Settlements:** rare, fuel-starved logistics instruments (mobile node / frontier extractor / show-of-force) — not predator-city core loop.

**Invention:** on-rails parts/tags; filter AI flavor away from ME/WWW/GG signatures; chassis families (rail, track, legs≠spider, barge, emplacement).
